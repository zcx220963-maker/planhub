```
  │              调用 Java Spring Boot API                      │

                           │
                           ▼
              ┌──────────────────────┐
              │   MySQL 数据库       │
              │   执行增删改查       │
              └──────────┬───────────┘
                         │

              ┌──────────────────────┐
              │   返回操作结果        │
              │   格式化响应          │

              ┌──────────────────────┐
              │     返回给用户          │
              └──────────────────────┘

可用工具列表：
- create_plan()        : 创建新计划
- update_plan()        : 更新计划
- delete_plan()        : 删除计划
- get_plan()           : 获取计划详情
- list_plans()         : 列出用户计划
- create_post()        : 发布社区帖子
- like_post()          : 点赞帖子
- comment_post()       : 评论帖子
- follow_user()        : 关注用户
- get_user_profile()   : 获取用户信息
- update_user_profile() : 更新用户信息
- get_statistics()     : 获取统计数据
```

```
记忆系统架构：
┌─────────────────────────────────────────────────────────────┐
│                     三层记忆架构                              │
├─────────────────────────────────────────────────────────────┤
│ 短期记忆 (Short-term)                                       │
│  - Redis List存储，保留最近20条消息                        │
│  - TTL: 2小时                                               │
│  - 用于上下文理解                                           │
├─────────────────────────────────────────────────────────────┤
│ 工作记忆 (Working Memory)                                    │
│  - Redis String存储，当前任务状态                           │
│  - TTL: 1小时                                               │
│  - 用于多步骤任务追踪                                       │
├─────────────────────────────────────────────────────────────┤
│ 用户偏好 (User Preference)                                   │
│  - Redis String存储，持久化                                 │
│  - 无过期时间                                               │
│  - 用于个性化推荐                                           │
└─────────────────────────────────────────────────────────────┘
```

使用说明：
1. 将上述流程图复制到README.md对应位置
2. 建议替换原来的文字描述，或放在文字说明之后
3. 在Gitee等支持ASCII的平台上显示效果最佳
4. 如需调整，可修改框内的中文说明
